## Saphira Linux lives here

Saphira development lives under a separate organisation:

**[https://github.com/SaphiraLinux](https://github.com/SaphiraLinux)**

Saphira is a source-built, musl-based Linux distribution with an independently maintained toolchain and package ecosystem. Development also includes native UEFI and Type-1 hypervisor research.

Public Saphira repositories include `recipes`, `saphira-llm`, `saphira-tokenizer`, `saphira-sjev-c` and others. The distribution source itself is not public yet.

See: [https://saphira.vm2.uk/](https://saphira.vm2.uk/)

## Projects — public repositories

Original work maintained under this organisation (`akadatalimited`):

### [PeaBrain](https://github.com/akadatalimited/PeaBrain)
Small brain. Big memory. No libc.

Low-level Assembly experiment in memory and minimal runtime — no libc. Active development.

### [BreathGSLB](https://github.com/akadatalimited/breathgslb) — `breathgslb`
IPv6-first authoritative DNS and GSLB engine in Go. Distinguishes local/private and public clients, serving RFC1918 or ULA answers where appropriate, with health-checked global steering for Internet-facing traffic.

Topics: `dns` `gslb` `ula` `rfc1918`

### [liquidgui](https://github.com/akadatalimited/liquidgui)
GUI for liquidctl. Python, MIT License. Desktop control for liquid cooling and hardware monitoring.

### [ngram-to-neural-network](https://github.com/akadatalimited/ngram-to-neural-network)
From simple n-gram to neural networks. C language study moving from classical n-gram models toward neural approaches.

### [breath-assist](https://github.com/akadatalimited/breath-assist)
A VAD + TTS agent for Linux (Arch if you please). Python, MIT License. Voice activity detection and speech synthesis agent experiment.
